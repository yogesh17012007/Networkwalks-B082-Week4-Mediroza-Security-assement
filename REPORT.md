# Mediroza Hospital Penetration Testing Report

## 1. Executive Summary

An authorized penetration testing assessment was conducted
against the Mediroza Hospital training environment.

The assessment covered four milestones:

- M1 – Initial Access
- M2 – Data Extraction
- M3 – Attack / Data Discovery
- M4 – Penetration Testing Report

## 2. Scope

Target:
Mediroza Hospital Training Environment

Assessment Type:
Authorized Educational Penetration Test

## 3. Assessment Summary

| Milestone | Status |
|-----------|--------|
| M1 – Initial Access | Completed |
| M2 – Data Extraction | Completed |
| M3 – Attack | Completed |
| M4 – Report | Completed |

## 4. Findings

### Finding 01 – Access Control

Access to protected patient-report resources was demonstrated
during the authorized assessment.

**Recommendation:**  
Implement strong authentication and proper authorization controls.

### Finding 02 – Weak Document Protection

The three protected PDF reports were successfully accessed during
the controlled security assessment.

**Recommendation:**  
Use strong passwords and application-level access controls for
sensitive documents.

### Finding 03 – Sensitive Information Exposure

Staff and shareholder information was obtained during the
authorized assessment.

**Recommendation:**  
Apply least-privilege access controls and restrict access to
sensitive information.

The defined penetration testing objectives were successfully
completed in the controlled educational environment.

Security controls should be strengthened and the environment
should be retested after remediation.

## Disclaimer

This assessment was performed only in an authorized and controlled
educational environment. No unauthorized production systems were
targeted.
